# Synthetic test data

Simulated CSV files in `inst/extdata/synthetic/`, generated by `dev/make_synthetic_data.R`
(fixed seed). None are real data. Locate them after installing with
`system.file("extdata", "synthetic", package = "stabilitest.viz")`.

| File | Rows | Use with |
|---|---|---|
| `two_sample_continuous.csv` | 120 | Welch / Wilcoxon / Brunner-Munzel / TOST mean (`arm`, `outcome`; two planted outliers) |
| `paired_bp.csv` | 40 | paired t / signed-rank (`before`, `after`) |
| `binary_response.csv` | 140 | Fisher / chi-square / prop / TOST prop and OR (`arm`, `responder`) |
| `binary_response_eligible.csv` | 200 | Significant Fisher result inside the validated profile, so stabilitest returns a label (use the validated settings) |
| `ancova_trial.csv` | 90 | `robustness_lm` (3-level `arm`, `age`, `baseline`, `change`; 4 missing outcomes) |
| `count_events.csv` | 100 | `robustness_glm` Poisson with offset (`events`, `exposure_years`) |
| `survival_cox.csv` | 120 | `robustness_surv` (`time_months`, `event`, `arm`, `age`) |
| `adsl.csv`, `adeff.csv`, `adtte.csv` | 100 / 300 / 100 | ADaM detection and mapping presets (M1): ADSL, BDS with `PARAMCD`/`AVISIT`/`ANL01FL`, ADTTE with `CNSR` (1 = censored) |

They are also listed in the app under "Synthetic files" in the Data step, and can be uploaded from disk.
